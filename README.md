# 🩺 SymptoAI – AI-Powered Symptom Checker

SymptoAI is a machine learning-based healthcare application that predicts diseases from user symptoms and provides severity analysis, medicine recommendations, and health reports.

🌐 Live Demo: https://symptoai-alpha.vercel.app

---

## 🚀 Features

✅ Symptom-based disease prediction

✅ Severity analysis

✅ Medicine recommendations

✅ Health report generation

✅ Interactive web interface

✅ Machine learning prediction model

## ⚙️ How It Works

1. User selects symptoms.
2. The frontend sends data to the Flask backend.
3. The machine learning model predicts the disease.
4. The system evaluates severity.
5. Medicine recommendations are generated.
6. A health report is displayed.
